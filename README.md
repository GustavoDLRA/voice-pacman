# **Voice Pac-Man**

This repository contains an implementation of Pac-Man that uses Whisper to interpret natural language voice commands It is meant to serve as a proof-of-concept for bilateral robot communication. 

If you'd like to try it out, follow these instructions:

1. Install uv (if not already installed):
```
https://docs.astral.sh/uv/getting-started/installation/
```
   

3. Clone the repo:
   ```
   git clone <your-repo-url>
   cd VoicePacman
   ```
5. Install dependencies and create the environment:
   ```
   uv sync
   ```
7. Run the game:
   ```
   uv run python run.py
   ```

You'll need an Nvidia GPU.
